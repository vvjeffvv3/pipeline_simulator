# Pipeline Atlas

데이터 엔지니어링 도구를 역할별로 찾아보고, 서비스 조건에 따라 파이프라인 초안을 만들어 비교하는 한국어 대시보드입니다.

## 기능

- 16개 역할에 걸친 데이터 플랫폼 도구 120개의 설명, 장점, 고려 사항, 추천 상황, 공식 문서 링크
- 키워드·분류·학습 난이도·제공 방식 검색, 북마크, 최대 네 가지 도구 비교
- 입력 데이터, 반영 주기, 처리 규모, 운영 환경과 여력에 따른 파이프라인 구성 시뮬레이터
- 선택 근거·운영 주의 사항, 샘플 데이터의 모의 처리·재시도, 설계 초안 내보내기

## 로컬에서 열기

Node.js가 설치되어 있어야 합니다. 의존성 설치 없이 실행합니다.

```sh
npm run dev
```

브라우저에서 `http://127.0.0.1:4187/`을 열면 됩니다.

## 구성

- `dist/index.html`, `dist/style.css`: 화면 구성과 반응형 스타일
- `dist/data.js`: 도구 목록과 분류 정보
- `dist/app.js`: 검색, 비교, 즐겨찾기, 조건 기반 설계 기능
- `server.cjs`: 로컬 미리보기용 작은 정적 웹 서버

사이트 호스팅을 위한 `dist/` 디렉터리는 `.openai/hosting.json`에도 지정되어 있습니다.

## 시뮬레이터 안내

설계 랩은 입력한 조건과 브라우저 안의 규칙을 바탕으로 한 설계 예시입니다. 외부 AI를 호출하거나 데이터 시스템에 연결하지 않으며, 모의 처리 시간과 건수는 실제 도구의 처리 성능을 측정한 수치가 아닙니다. 도구 정보와 선택 기준은 학습용 요약이므로 실제 사용 전 각 도구의 공식 문서와 현재 운영 조건을 확인하세요.
